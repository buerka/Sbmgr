# 策略参考

## 配额与计量口径

配额支持三种计量口径：

- 上传与下载之和；
- 仅上传；
- 仅下载。

后台始终分别保存原始上传和下载数据。计量口径只影响配额进度、阶梯限速、配额停用和订阅用量响应头。

月度账期可配置每月 1–28 日作为重置日。账期和界面日期以产品默认时区 `Asia/Shanghai` 计算，数据库时间保留时区信息。账期结束时会归档用量并建立新的计费周期。手动重置会先建立实时统计基线，避免后续同步重新计入重置前流量。

## 阶梯限速

阶梯策略由两组“用量阈值 + 基础速度百分比”组成。例如：

```text
达到 <THRESHOLD_1>% → 使用节点基础速度的 <RATE_1>%
达到 <THRESHOLD_2>% → 使用节点基础速度的 <RATE_2>%
达到 100%          → 按配额策略停用
```

各项数值可在 CUI 中修改。节点基础速度为不限速时，没有可供折算的基准，因此不会应用百分比降速。

## 异常流量保护

滑动窗口规则在指定分钟内累计实际双向流量，超过阈值后执行临时处罚：

- **软封禁**：保留身份与连接能力，将相关节点限制到配置的低带宽。
- **硬封禁**：从受管入站移除相关身份，并关闭现有连接。

处罚时长、动作和软封速度均可配置。到期后恢复节点原有限速。手动解除处罚不会关闭异常流量规则。

## 来源 IP

来源规则记录服务器观察到的公网出口 IP。用户级与设备级规则同时启用时，连接需要满足两层规则。

- **动态单活**：同一公网 IP 后可有多台设备和多个连接；旧 IP 静默达到换绑等待时间后，新 IP 可接管。
- **自动固定**：首次观察到的 IP 成为固定绑定，后续其他 IP 被拒绝。
- **手动固定**：使用运维方提供的一个或多个允许 IP。
- **临时替代**：在有效期内用临时 IP 集合替代固定绑定。
- **仅告警**：记录并报告变化，不阻止连接。

移动网络、家庭宽带或运营商 NAT 可能频繁更换公网 IP。此类环境适合动态单活、较短换绑等待或仅告警模式。

## 访问与并发

用户和设备均可设置：

- 允许域名；
- 禁止域名；
- 禁止目标端口；
- 最大活跃连接数；
- 超限时仅告警、禁用设备或禁用用户。

填写允许域名后形成白名单。域名规则支持后缀匹配；端口规则支持多个值。规则按认证后的 `auth_user` 应用，不会作用于基础配置中的非托管身份。

## 生效时机

管理状态保存后，涉及身份、路由、访问、来源 IP 或限速的变化需要应用配置。后台触发的配额、到期和临时处罚会自动尝试应用；失败时保留待应用状态并继续告警和重试。
