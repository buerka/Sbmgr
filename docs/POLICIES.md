# 策略参考

规则按认证身份作用于受管节点。用户与设备规则同时启用时须同时满足；基础模板的非托管身份不受影响。

| 策略 | 语义与边界 |
| --- | --- |
| 配额 | 裸数字按 GiB，0 不限；双向/仅上传/仅下载口径影响配额、阶梯限速、停用与订阅用量头，原始上下行始终分别保存 |
| 账期 | 月度重置日为 1–28，默认时区 `Asia/Shanghai`，持久时间保留时区；周期结束归档。手动重置先建立实时基线，避免重复计入旧流量 |
| 阶梯限速 | 两组“用量百分比 → 节点基础速度百分比”；基础速度不限时无法按比例降速，达到配额按策略停用 |
| 异常流量 | 滑动窗口累计实际双向流量；软封禁临时降速，硬封禁移除身份并关闭连接；到期恢复原速，手动解除不关闭规则 |
| 访问 | 允许域名形成白名单；允许/禁止域名支持后缀匹配，可禁止多个目标端口 |
| 并发 | 超限可告警、禁用设备或用户；自动禁用默认 10 分钟，恢复仍受配额、到期及其他规则限制；手动禁用清除自动恢复标记 |

sbmgr 不按来源 IP 限制用户或设备连接，也没有设备来源 IP 限制的配置入口。升级时自动解除旧的动态单活、自动学习、固定名单和临时替代规则及绑定；基础模板中的手工规则不受此迁移影响。连接记录中的来源地址仅供观察，NAT 后多设备可能共用一个地址。访问记录不含 HTTPS 路径或正文。连接数量由日志推断，最多跟踪 4096 条；日志丢失或超出容量时可能低估，不作为精确内核并发防火墙。旧状态中无禁用原因的设备不会被推测为应自动启用。

手动修改身份、路由、访问、限速后需“应用配置”。后台配额、到期和临时处罚自动尝试应用；失败保留待应用状态，继续告警并重试。
