# 用户指南

列表用 `↑/↓` 或 `j/k` 移动，`Enter` 打开，`Esc` 返回；完整操作见页面菜单，快捷键见页脚。

## 常用流程

| 操作 | 步骤 |
| --- | --- |
| 创建用户 | 用户 → 新建 → 配额、到期、初始节点、上下行限速 → 保存 → 应用配置；同时生成默认设备和节点身份 |
| 设备管理 | 用户详情 → 设备：新增、启停、轮换身份、分配节点或设置设备策略 |
| 批量管理 | 勾选用户 → 批量管理；“保持不变”不覆盖，清除需明确选择，全部校验成功后统一提交 |
| 线路 | 管理入口、出站与端点；主从线路先在运维中心编排并应用，再分配给设备，见[主从管理](MESH.md) |
| 订阅地址 | 订阅交付或设备页 → `Enter` 菜单；`c` 复制、`w` 保存、`z` 二维码，见[订阅服务](SUBSCRIPTIONS.md) |
| 查看统计 | 用户详情查看上下行、配额、连接、来源和访问目标；非表单页自动刷新 |

配额裸数字按 GiB，`0` 为不限。模板复制策略、布局和授权，身份、token、mark 重新生成，统计与动态 IP 状态清空。完整规则见[策略参考](POLICIES.md)。

基础模板中的非托管身份保留；首页只展示当前管理对象。

## 生效与导出

| 变化 | 生效方式 |
| --- | --- |
| 身份、启停、授权、路由、来源、访问或限速 | 保存后“应用配置” |
| 主从拓扑 | “应用主从拓扑”；设备分配变更再“应用配置” |
| 订阅 token 轮换 | 保存即撤销旧地址，无需应用 |
| 订阅监听、证书、开关 | 需重启守护进程，CUI 保存时自动执行 |

应用失败恢复原运行配置与限速规则。保存管理数据和应用运行配置是两个阶段。

静态 Mihomo YAML 只包含该设备授权节点，导出后不随状态变化；订阅每次请求实时生成。Mihomo 母版保留 DNS、分组、规则和注释，生成时重建代理并替换身份。

## 表单

`↑/↓`、`Tab/Shift+Tab` 切字段；`←/→` 移动光标或选项；`Home/End` 到首尾；`Backspace/Delete` 删除；`Ctrl+U` 清空；`Enter` 确认，`Esc` 取消。

密码不预填、不回显，留空保留原值。完整代理 JSON 使用私有草稿文件编辑，提交前校验。
