# 用户指南

浏览器打开管理员地址并登录。左侧按“总览、用户与设备、线路与服务器、订阅交付、运维与备份”组织功能；顶部显示待生效状态。首次部署见 [Web 管理](WEB_ADMIN.md)。

## 常用流程

| 操作 | 步骤 |
| --- | --- |
| 创建用户 | 用户与设备 → 新建用户 → 配额、到期、初始节点 → 保存 → 应用配置 |
| 设备与授权 | 点击用户列表任意一行 → 设备与线路 → 分配线路 → 选择设备 → 勾选已连接线路 → 保存 → 应用配置；原授权自动勾选。用户详情可新增设备、修改节点限速 |
| 批量设置 | 用户与设备 → 批量修改用户 → 多选用户 → 设置要改的字段 → 确认；任一校验失败则全批取消 |
| 用户分组 | 用户分组 → 新建或编辑 → 开启统一规则 → 成员管理；配额每人独立计算。用户详情「分组与继承」可设置个人覆盖，移动成员默认保留当前配置，详见 [用户分组](USER_GROUPS.md) |
| 策略 | 点击用户行 → 基本设置 / 访问控制 / 流量保护；当前值直接显示在表单中，设备卡提供独立策略 |
| 线路 | 线路与服务器 → 选择入口 → 从入口圆点拖到落地（也可点击连接）→ 保存线路 → 应用拓扑 → 为用户分配线路；服务器和基础落地另在「服务器与落地」页签维护 |
| 用户登录 | 点击用户行 → 面板登录 → 生成邀请链接 → 发给用户自行设置密码；24 小时有效、成功后立即作废。已开通账号可停用或重置密码 |
| 自助设备 | 用户详情 → 设置设备总名额（0 关闭，1–100 开启）→ 用户登录后在「我的设备」新增、改名、删除设备或重置订阅链接 |
| 网站数据 | 管理员点击用户行 → 数据看板；普通用户登录 → 数据看板，或从「我的设备」直达该设备。可切换设备、近 1/7/30 日、网站筛选及排序 |
| 机器流量 | 总览 → 机器流量 → 为每台机器设置开始日和循环间隔（日/月/年）→ 查看本期上传、下载、合计、下次换期日及采样覆盖；点击「历史周期」分页查看旧期 |
| 管理账号 | 管理账号 → 修改已填入的用户名，或输入新密码 → 验证当前密码 → 保存并重新登录；新密码留空保留原密码 |
| 订阅 | 用户配置 → 订阅交付 → 点击「订阅地址」选择复制链接或下载 TXT，也可下载 YAML；全局订阅页仍可统一交付 |
| 运维 | 校验配置、健康和 Fleet 检查；点击「状态备份」或「操作审计」进入专页，按需搜索、分页查看和恢复备份 |
| 备份清理 | 状态备份 → 设置保留期限 → 填保留天数并确认；0 关闭，默认关闭。页面显示每份大小、到期时间和备份目录总大小 |

Web 配额裸数字按 GiB，`0` 不限，也可填 `500M` 或 `100G`。CLI 容量建议始终写单位。复制用户策略会重新生成身份、token 和 mark，清空累计统计；基础模板中非托管身份保持原样。完整规则见 [策略参考](POLICIES.md)。

## 保存与生效

| 变化 | 生效方式 |
| --- | --- |
| 身份、启停、授权、路由、访问、限速 | 保存后“应用配置” |
| 主从拓扑 | “应用拓扑”；设备节点变更再“应用配置” |
| 面板邀请、登录停用、重置密码 | 保存后立即生效，撤销相应旧邀请或旧会话；不改代理配置 |
| 用户自助新增、删除设备 | 保存后后台自动应用代理配置，通常在 1 分钟内完成；待管理员配置尚未应用时拒绝自助变更 |
| 自助改名、重置订阅链接 | 保存后立即生效；只有重置链接会使旧订阅地址失效 |
| 机器续费周期 | 保存后立即按新循环规则重算本期显示，无需应用配置；失败保留原设置，旧采样与历史周期保留，未采集的流量无法补录 |
| 订阅 token、停用后的订阅交付 | 保存后立即校验，无需重启 |
| 订阅监听、证书、开关 | `sbmgr service restart` 后生效 |
| 备份保留期限 | 下一轮后台维护生效，无需应用配置；只清理到期的手动和每日状态备份，每类保留最新一份 |

页面显示后台任务结果。失败时保留或恢复原运行配置；保存业务状态和应用配置是两个阶段。连接策略不是提交表单后立即完成重载。

用户配置按基本设置、分组与继承、设备与线路、访问控制、流量保护、订阅交付、数据看板、用量与记录、面板登录分类。各设置区单独保存；切换标签保留未保存的输入，离开用户页前提示放弃修改。后台状态刷新不会覆盖正在编辑的表单。

新建用户留空的策略字段继承默认分组；该组未设置的项采用原默认值。编辑表单只提交变化的字段，原值在修改时显示；清空列表会移除规则，清空到期日会移除有效期限制，编辑时数值字段不允许留空。危险操作在对话框明确确认后才提交。完整出站 JSON 仅接受输入，提交后清空；已保存的密码和代理 JSON 不回显。

订阅每次重新校验设备权限，静态 YAML 下载后不会自动更新。节点组合只出现于已获授权的设备。主从入口、落地和订阅模板行为继续沿用原模型，见 [主从管理](MESH.md) 与 [订阅服务](SUBSCRIPTIONS.md)。

机器流量按物理网卡计量，包含非代理流量，与用户配额统计相互独立。续费开始日作为循环锚点，按所选日/月/年间隔自动换期；日期按管理主机本地时间，周期结束日包含当日。月末和闰年锚点按日历规则处理，不逐次漂移。总览只读取当前期，历史从首次机器流量采样所属周期起在专页分页查询，不生成采样前的空白历史。采样覆盖率与首末采样时间提示数据完整性；采样启动前、采样中断及跨期边界的未知流量不能补算或当作零。修改规则只重算新一期显示，旧采样和历史周期保留。 旧起止日设置会自动转换：若旧结束日次日对应原锚点的整月或整年边界，就沿用月/年周期；否则按旧首期的自然日天数循环。修改规则时旧期按修改时刻结算，新规则从该时刻分配新采样；跨修改边界的单次采样不拆分，两侧均记为未知。历史卡显示规则实际生效及结算时刻。

网站数据看板按已采集连接的实际上传、下载字节汇总，不从用户总用量按网站分摊。次数表示连接次数，不是页面浏览量；目标只显示域名或目标 IP，不显示 HTTPS 路径。时间范围和趋势按收到流量增量的 UTC 采集日展示，断线跨日无法回填实际发生日。覆盖状态会标出采集开始时间、时间缺口与不可用范围；尚未采集不能当作零流量。管理员可查看所选用户，普通用户只能查看本人；设备筛选也限定在该用户的设备内。

## 普通用户

收到管理员邀请后设置自己的密码，再用同一面板地址登录。个人页面包含「我的状态」「我的设备」「数据看板」「我的订阅」「密码设置」，只显示自己的服务。忘记密码请联系管理员重置；未激活的邀请过期后请管理员重新生成。新建与复制用户不会带入面板密码。

管理员设置的设备名额包含停用设备。新增设备可从自己已获授权的设备复制线路与节点设置，设备身份和订阅链接由程序重新生成，所有设备仍共用该用户的配额。名额调低不会删除旧设备；已有设备超过新上限时不能再新增。用户只可操作自己的设备，重置订阅链接后旧地址立即失效，已导入客户端配置中的 UUID 不变。新增、删除设备待自动应用完成后才能用于代理连接。
