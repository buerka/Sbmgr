# 用户指南

本文描述 sbmgr CUI 的通用工作流。页面底部会显示当前上下文可用的快捷键；高频操作也可从菜单进入。

## 页面结构

- **用户**：创建、筛选、选择和批量管理用户。
- **用户详情**：查看用量、速率、配额、设备、节点、来源 IP、连接和访问摘要。
- **线路**：管理客户端入口、sing-box 出站与端点，并查看健康检查结果。
- **运维**：管理告警、订阅、备份、审计、同步和配置应用。

列表使用 `↑/↓` 或 `j/k` 移动，`Enter` 打开详情，`Esc` 返回。`?` 或页面菜单键可显示完整操作列表。

## 创建用户

1. 在用户列表选择“新建用户”。
2. 设置用户名、配额、计量口径和到期日。
3. 从基础配置提供的节点模板中选择初始节点。
4. 设置该节点的上传、下载限速。
5. 保存后应用配置。

系统同时创建一台默认设备，并为初始节点生成独立 UUID、`auth_user` 和 routing mark。配额输入支持带单位的值；裸数字按 GiB 解释，`0` 表示不限。

通过“套用模板”创建用户时，配额、策略、设备布局、节点授权和限速会复制；UUID、订阅 token、routing mark、流量、访问记录和动态 IP 状态会重新生成或清空。

## 设备与节点

每台设备拥有独立订阅 token 和一组独立节点身份。设备管理支持：

- 新增、启停和删除设备；
- 轮换设备的全部 UUID；
- 设置设备级来源 IP 与访问规则；
- 为设备分配或移除节点；
- 修改每个节点的上传、下载限速；
- 导出该设备的 Mihomo YAML 或显示订阅二维码。

轮换、启停、删除和授权变更需要应用配置后才会进入 sing-box 运行配置。

## 用户与批量管理

用户列表可勾选多个用户并打开批量管理。批量操作支持状态、配额、计量口径、账期、阶梯限速、节点速率、异常流量保护、来源 IP 和访问规则。

“保持不变”的字段不会覆盖原值；明确的清除操作会在确认页显示。批量修改先在内存副本中验证，全部对象通过后才在一个 SQLite 事务内提交。

## 配置导出

静态导出文件使用带时间戳的名称，并且只包含所选设备已获授权的节点。静态文件是快照，后续策略或地址变化不会修改已导出的文件。

可选的 Mihomo 母版用于保留 DNS、代理组、规则集、分流规则和注释。生成过程会重建 `proxies`，过滤无权使用的节点，并替换设备对应的连接身份。

设备订阅在每次请求时实时生成，适合客户端自动更新。详细行为见 [订阅服务](SUBSCRIPTIONS.md)。

## 统计与审计

用户详情显示以下信息：

- 当前上传、下载速率及近期趋势；
- 原始上传、下载用量及配额进度；
- 设备、节点和对应限速；
- 活跃连接、来源公网 IP 和访问目标；
- 到期、账期、告警和临时处罚状态。

非表单页面会定期重新读取后台快照。访问记录按用户、设备、节点和目标聚合；记录内容不包含 URL 路径或传输正文。

## 表单编辑

- `↑/↓`、`Tab`、`Shift+Tab`：切换字段。
- `←/→`：移动文本光标，或切换固定选项。
- `Home/End`：跳到文本首尾。
- `Backspace/Delete`：删除光标前或光标处字符。
- `Ctrl+U`：清空当前文本字段。
- `Enter`：确认当前步骤或提交。
- `Esc`：取消并返回。

密码字段不预填、不回显；留空表示保留原值。完整代理 JSON 通过权限受限的临时草稿编辑，并在提交前进行结构与 sing-box 校验。

## 应用配置

“保存状态”和“应用配置”是两个阶段。前者提交管理数据，后者生成并加载 sing-box 与 nftables 配置。应用操作会显示验证结果；失败时恢复上一份运行配置和限速规则。
